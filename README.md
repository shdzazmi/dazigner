# dazigner

Neo-brutalist professional portfolio homepage built with **Next.js + TypeScript**.

## Stack
- Next.js App Router
- TypeScript
- CSS (custom neo-brutalist design system)

## Theme
- Canary yellow `#FFE135`
- Jet black `#1A1A1A`
- Off-white `#DBDBDB`

## Features
- Mouse parallax hero card
- Custom canary cursor interaction
- Hover reveal overlays for project highlights
- Scroll-triggered reveal animations
- Asymmetric bento grid layout
- Testimonials section
- Contact form panel
- DM Sans + Plus Jakarta Sans typography

## Run locally
```bash
npm install
npm run dev
```
